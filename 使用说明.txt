PDF 工具箱 使用说明（v1.4）
============================

【启动】双击「PDF工具箱.exe」，或使用桌面快捷方式。

本工具包含四个功能，全部平铺在窗口顶部的标签栏，点一下即可切换：
    PDF 转 Word  |  PDF 合并  |  PDF 转图片  |  Office 转 PDF
GPU 加速支持、深色模式、关于等次级功能在窗口右上角的「⋯」里。


════════════════════════════════════════
一、PDF 转 Word（主界面）
════════════════════════════════════════
1. 点击「添加 PDF」或直接把 PDF 文件拖进窗口
2. 选择转换模式和参数（一般默认即可）
3. 点击「开始转换」，输出 docx 与源 PDF 同目录

转换模式说明：
- 自动判定（推荐）：逐页判断。文字型 PDF 走保排版直转；扫描页自动走
  版面分析 + OCR 重建
- 强制保排版直转：全部按文字型处理（适合纯文字 PDF，速度最快）
- 强制 OCR 重建：全部按扫描页处理（适合文字层损坏的文档）

功能特性：
- 文字型 PDF：保留字体、字号、段落、表格与插图位置
- 扫描版 PDF：版面分析切分文本/图片区域，OCR 识别后重建为可编辑文档
- 图片中的文字：自动检测并提取为可编辑段落（灰色斜体、带「图内文字：」
  标记），图片本身保留在原位置
- 支持批量转换、拖拽添加、进度显示与日志查看
- 自动检测 NVIDIA GPU 并启用 CUDA 加速（无显卡时自动使用 CPU）

参数说明：
- 渲染 DPI：扫描页渲染精度。默认 200；文字细小模糊时可试 300（更慢）
- 提取图内文字：关闭后跳过图片文字检测，速度略快


════════════════════════════════════════
二、PDF 合并（顶部「PDF 合并」标签页）
════════════════════════════════════════
1. 把多个 PDF 拖进列表（或用「添加文件」）
2. 用「上移 / 下移」调整合并顺序
3. 双击列表项可为该文件指定页面范围，例如 1-5,8（留空表示全部页面）
4. 指定输出文件名（默认「合并结果_日期时间.pdf」）
5. 点击「开始合并」

说明：
- 勾选「保留源文件书签」后，每个源文件的书签会归到以文件名命名的
  一级书签下，便于在合并结果里跳转
- 加密（需要密码）的 PDF 会被跳过并在日志中提示，不影响其余文件合并
- 实测速度：7 页合并约 0.1 秒，100 页约 0.3 秒


════════════════════════════════════════
三、PDF 转图片（顶部「PDF 转图片」标签页）
════════════════════════════════════════
1. 把 PDF 拖进列表
2. 选择图片格式：PNG（无损，默认）/ JPG / WebP / BMP / TIFF
3. 选择分辨率 DPI：150（默认，速度快）/ 200 / 300
4. 选择输出模式：
   - 多张独立图片：每页一张，命名为「前缀_0001.png」递增
   - 单张拼接长图：所有页面垂直拼接成一张长图；
     超过「长图单卷上限」（默认 20000 像素）会自动分卷为
     「前缀_长图_1.jpg」「前缀_长图_2.jpg」...
5. 可选：JPG 质量（60-100）、页间距、文件名前缀、输出目录

说明：
- 未指定输出目录时，会在源 PDF 所在目录下新建「<文件名>_images」文件夹
- JPG 不支持透明，程序会自动铺白底
- 实测速度（150 DPI）：PNG 约 68 毫秒/页，JPG 约 103 毫秒/页；
  30 页文档 PNG 约 2 秒
- 长图模式下每页都会占内存，页数很多时建议用分卷（默认已开启）


════════════════════════════════════════
四、Office 转 PDF（顶部「Office 转 PDF」标签页）
════════════════════════════════════════
支持格式：Word（.docx）、Excel（.xlsx）、PowerPoint（.pptx）

1. 把 Office 文件拖进列表
2. 「转换引擎」保持「自动选择」即可
3. 可选：指定输出目录（默认生成在源文件同目录，同名 .pdf）
4. 点击「开始转换」

引擎说明（页面顶部会显示当前可用的引擎）：
- Word 文档（.docx）：程序自带一个轻量排版引擎，**不需要装任何办公软件**
  就能直接转换（实测中文正常，约 1.5 秒/文件）
- Excel / PPT：需要排版引擎，按以下优先级自动选择
    ① 本机已装的 Microsoft Office / WPS（保真度最高，最快）
    ② 内置 LibreOffice（仅全功能版提供）
  两者都没有时，页面会提示并提供下载入口

关于 LibreOffice
    LibreOffice 是免费开源的办公套件，安装包约 358 MB。本程序只在
    「Excel / PPT 转 PDF」时才需要它，转换 Word 文档不需要。
    下载入口（国内镜像，速度较快）：
      https://mirrors.tuna.tsinghua.edu.cn/libreoffice/libreoffice/stable/26.8.1/win/x86_64/LibreOffice_26.8.1_Win_x86-64.msi
    也可以在 PowerShell 里一行装好（Windows 10 1809+ 自带 winget）：
      winget install TheDocumentFoundation.LibreOffice
    装完回到本程序，引擎会自动识别，不需要重启。

说明：
- 转换过程中会在后台启动 Office，完成后自动关闭；
  程序只会清理自己启动的后台进程，不会动你正在编辑的文档
- 加密或需要密码的 Office 文件无法自动转换


════════════════════════════════════════
五、命令行用法（可选）
════════════════════════════════════════
本目录下的 pdf2word-cli.exe 支持命令行调用，便于批量/脚本使用。

PDF 转 Word（v1.3 及以前的用法完全兼容）：
    pdf2word-cli.exe 文件.pdf
    pdf2word-cli.exe 文件.pdf --mode scan --dpi 300
    pdf2word-cli.exe 文件.pdf -o 输出.docx

PDF 合并：
    pdf2word-cli.exe merge a.pdf b.pdf -o 合并结果.pdf
    pdf2word-cli.exe merge a.pdf b.pdf -o out.pdf --range 1-5 --range 2

PDF 转图片：
    pdf2word-cli.exe image 文件.pdf -o 输出目录 --format png --mode separate --dpi 150
    pdf2word-cli.exe image 文件.pdf -o 输出目录 --format jpg --mode long --max-height 20000

Office 转 PDF：
    pdf2word-cli.exe office a.docx b.xlsx -o 输出目录
    pdf2word-cli.exe office a.docx --engine com        # 强制本机 Office
    pdf2word-cli.exe office a.docx --engine libreoffice  # 强制内置 LibreOffice

不带参数运行 pdf2word-cli.exe 时同样打开图形界面。


════════════════════════════════════════
六、GPU 加速支持（右上「⋯」按钮）
════════════════════════════════════════
  下载 GPU 加速支持...
    适用于精简版用户。点击后程序会从国内镜像源（清华/阿里云）下载
    NVIDIA CUDA 运行时库和 PaddlePaddle GPU 引擎（约 1.5 GB），
    安装完成后重启程序即可启用 GPU 加速，OCR 速度提升约 4-5 倍。
    支持断点重试，网络中断后可重新点击继续下载。

  检查 GPU 状态
    显示当前系统的 NVIDIA 显卡型号、GPU 支持包安装状态和推理设备
    （GPU/CPU），帮助判断 GPU 加速是否正常工作。

  卸载 GPU 支持...
    删除已安装的 CUDA 库，恢复为 CPU 模式。卸载后需重启程序生效。

提示：GPU 加速只影响「PDF 转 Word」里的扫描页识别（OCR）。
合并、转图片、Office 转 PDF 三个功能与 GPU 无关。


════════════════════════════════════════
七、界面与交互技巧
════════════════════════════════════════
深色模式
    右上角「⋯」→ 深色模式。首次启动会自动跟随 Windows 的应用主题设置，
    手动切换后在本次运行内保持。

文件列表
    - 直接把文件拖到虚线框里即可添加；拖动时边框会变成蓝色
    - 鼠标移到文件行上，右侧出现「✕」可单独移除
    - 右键单击文件行：打开文件 / 打开所在目录 / 从列表移除
    - 合并页可用「上移 / 下移」调整顺序，双击某一项设置页面范围

进度与结果
    - 转换时底部状态栏显示「转换中…」和百分比，按钮同时变为停止按钮
    - 全部成功：右上角弹出提示
    - 有文件未完成：弹出"处理未完成"报告，逐个列出失败文件与原因，
      可直接点「只重试这 N 个」—— 已经成功的文件不会重复处理
    - 需要更多细节时，点报告里的「查看详细日志」，或展开页面底部的日志卡片

日志
    日志默认折叠成一行摘要，点右侧「详细日志 ▾」展开，避免界面被技术信息刷屏。


════════════════════════════════════════
八、版本说明
════════════════════════════════════════
  精简版（约 170 MB）
    - 不含 CUDA 库，默认 CPU 推理，可通过「⋯ → 下载 GPU 加速支持」在线升级
    - 不含 LibreOffice：「Office 转 PDF」需要本机已安装 Office 或 WPS
    - 适合已装 Office、配置一般或希望安装包小的用户

  全功能版（约 400-560 MB）
    - 内置 LibreOffice：没有装 Office/WPS 也能做 Office 转 PDF
    - 同样可通过「⋯ → 下载 GPU 加速支持」升级 GPU 加速
    - 适合未安装 Office 的用户

  两个版本使用不同的安装标识，可以同时安装，互不冲突。


════════════════════════════════════════
九、注意事项
════════════════════════════════════════
- 首次做扫描页转换较慢属正常现象（加载 OCR 与版面分析模型）
- 若程序安装在含中文的目录，首次运行时会自动把模型复制一份到
  C:\Users\<用户名>\AppData\Local\PDF2WordTool\models，属正常现象，
  请勿删除该目录
- 请勿删除程序目录下的 models 文件夹（内置 AI 模型）
- 精简版下载 GPU 支持后，需重启程序才能启用 GPU 加速
- 扫描件为整页图片，转换结果追求「内容完整、版式接近」，
  无法做到与原件像素级一致
- 低置信度识别结果建议人工校对
